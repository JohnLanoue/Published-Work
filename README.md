The general intent of this repository is to showcase my favorite python projects.  Most of these were projects from my Graduate courses.  

File Name	                    File Type	Description	Production Ready? 	Operation Instructions
Remoteless Control	          Python Project	Pet Project from Paternatiy: Leveraging MediaPipe, we use the camera to track hand gestures: Are you pointing and gesturing up/down/left/right.   It’s far from professional grade, but it was a fun project to keep the lights on in my head leveraging a more agentic approach to AI.  	Yes 	Download and load “Main.py”.  The additional files include supporting development files.  
Stock Market Predictor (NLP)	Python Notebook	Graduate Capstone Project: This will scrape articles and candlestick data for any stock symbol.  Leveraging NLP/ML processes, we come up with a buy/sell signal in a 2 day window.  Unforunatelly, this is not a money printing machine… yet. 	Depreciated: Yahoo Finance API is depreciated and migration would require a premium service.   	Read only Python notebook.  Would be compellable if stock market data is upgraded.  
Stock Market Predictor (LSTM)	Python Notebook	Graduate Final Project:  This only scrapes candle stick data and trains prior day stock prices to see a buy/sell signal for the upcoming days using an LTSM.  	Depreciated: Yahoo Finance API is depreciated and migration would require a premium service.   	Read only Python notebook.  Would be compellable if stock market data is upgraded.  
Heapq generation	            Python Notebook	This reads books (a book about NLP by default) and uses Heapq to summarize the information.  ChatGPT before ChatGPT using conventional NLP methods and not pre-trained transformers.  	Compiles in ipnyb.  Migrate to production ready file	Download and run the files.
